# Website Settings — Visual Assets (Pic)

This directory organizes visual assets associated with the website settings and branding.

- `favicon.ico`: Browser tab icon (configured at `/favicon.ico`)
- `og-image.png`: OpenGraph social share card preview (1200x630px recommended)
- `logo-light.png`: Light mode brand logo (`/logos/logo1.png`)
- `logo-dark.png`: Dark mode brand logo (`/logos/logo2.png`)
